# SailPoint Angular SDK

The Angular SDK lets you call the SailPoint APIs from an Angular application.

## Documentation

**Read the [SDK documentation](https://developer.sailpoint.com/docs/tools/sdk) on
developer.sailpoint.com.** It covers installation, authentication, configuration,
and code examples.

## Installation

```bash
npm install @sailpoint/angular-sdk
```

## Support

Ask a question on the [SailPoint Developer Community forum](https://developer.sailpoint.com/discuss)
or open an issue in the
[GitHub repository](https://github.com/sailpoint-oss/angular-sdk/issues).
